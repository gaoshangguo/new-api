# 安装部署

## Docker 部署（推荐）

```bash
# 创建目录
mkdir new-api && cd new-api

# 下载 docker-compose 文件
curl -O https://raw.githubusercontent.com/QuantumNous/new-api/main/docker-compose.yml

# 启动
docker compose up -d
```

访问 `http://localhost:3000`，默认账号 `root`，密码 `123456`。

## 环境变量

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `SQL_DSN` | 数据库连接串 | 自动检测 |
| `REDIS_CONN_STRING` | Redis 连接串 | — |
| `SESSION_SECRET` | 会话加密密钥 | 随机生成 |
| `CHANNEL_KEY_MASTER_KEY` | 渠道密钥主密钥（恰好 32 字节） | 自动生成 |
| `GIN_MODE` | 运行模式 | release |

## 数据库支持

- SQLite（默认，零配置）
- MySQL 5.7.8+
- PostgreSQL 9.6+

通过 `SQL_DSN` 环境变量切换数据库。
