# 常见问题

## 我的 Key 不能用了？

1. 检查 Key 是否过期（控制台 → API Keys → 过期时间）
2. 检查 Key 的剩余额度（`remain_quota`、日预算、月预算）
3. 检查 IP 白名单是否限制了你的 IP
4. 检查模型白名单是否包含你要调用的模型

## 为什么请求返回 429？

429 表示被限流。可能的原因：

- 超出了 Key 的日/月预算
- 超出了 RPM（每分钟请求数）限制
- 超出了并发限制
- 用户分组或模型有全局限流

在日志中查看具体错误信息，或调整 Key 的限流配置。

## 如何查看我的消费明细？

进入 **财务明细** 页面，可按项目、Key、模型、时间范围筛选，查看账本流水和消费明细，支持 CSV 导出。

## 充值后余额未更新？

充值通常即时到账。如果未到账，查看充值记录中的状态，或联系平台管理员。

## 支持哪些模型？

进入 **模型广场** 查看所有可用模型。模型由平台管理员配置和管理。

## 如何联系支持？

联系平台管理员获取帮助。在提交问题时，请提供请求 ID（可在使用日志中查看），不要提交完整的 Key 或敏感信息。
