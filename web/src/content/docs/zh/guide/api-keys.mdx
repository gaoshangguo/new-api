# API 密钥管理

API 密钥（Key）是调用平台接口的凭证。每个 Key 绑定到你的账户，可以设置独立的额度、权限和限制。

## 创建 Key

1. 进入控制台 → **API Keys** 页面
2. 点击「创建 Key」，填写名称
3. 设置总预算（`remain_quota`）、日预算（`daily_quota`）、月预算（`monthly_quota`），0 表示不限
4. 可选：设置模型白名单（`model_limits`）、渠道白名单（`channel_limits`，JSON 格式）、IP 白名单、并发限制、RPM/TPM 限流
5. 创建后**立即复制明文 Key**，关闭后无法再次查看明文（需二次验证）

## Key 预算与限制

| 字段 | 说明 |
| --- | --- |
| 总预算 | Key 的总可用额度，耗尽后请求返回 403 |
| 日预算 | 自然日额度上限，超限返回 429 |
| 月预算 | 自然月额度上限，超限返回 429 |
| 模型白名单 | 限制 Key 可使用的模型列表 |
| 渠道白名单 | 限制 Key 可走的上游渠道（JSON：`{"channels":[1,2]}`） |
| IP 白名单 | 限制调用来源 IP |
| 并发限制 | 同时处理中的请求数上限 |
| RPM | 每分钟请求数上限 |
| TPM | 每分钟 Token 预估上限 |

## 安全建议

- 不要在代码中硬编码 Key，使用环境变量
- 为不同应用创建不同的 Key，方便追踪用量和独立控制
- 定期轮换 Key
