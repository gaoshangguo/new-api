# 任务管理

异步任务（如图像生成、视频生成、音频处理）的状态查询和结果获取。

## 支持的异步任务类型

- **Midjourney**：图像生成（imagine、upscale、variation 等）
- **视频生成**：Sora、Kling、Jimeng 等
- **音频生成**：Suno 等
- **SwapFace**：换脸任务

## 查看任务

进入 **任务日志** 页面，可查看所有异步任务的：

- 任务 ID、平台、类型
- 状态（pending/processing/succeeded/failed）
- 消耗额度
- 创建时间、完成时间

## 任务状态查询

异步任务提交后，客户端可通过轮询接口查询任务状态和获取结果。具体接口见 API 参考。
