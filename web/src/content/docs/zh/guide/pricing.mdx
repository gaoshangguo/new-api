# 模型定价

进入 **模型广场** 查看所有可用模型的定价信息。

## 定价展示

模型广场按计费模式展示价格：

- **按量计费**：输入/输出 Token 单价
- **按时长计费**：每秒/每分钟价格（视频模型）
- **按次计费**：每次生成价格（图像模型）

## 筛选

可按以下维度筛选模型：

- **端点类型**：Chat、Response、Anthropic、Gemini、Embeddings、Image、Video
- **供应商**：OpenAI、Anthropic、Google、DeepSeek 等
- **计费类型**：按量/按时长/按次

## 模型详情

点击模型卡片可查看：

- 上下文窗口、最大输出 Token
- 输入/输出价格明细
- 支持的端点类型
- 各语言的 **API 调用示例**（cURL、Python、TypeScript、JavaScript）
