# 使用日志

使用日志记录每次 API 调用的详细信息，帮助你追踪用量、排查问题和审计。

## 查看日志

进入 **使用日志** 页面，可以看到：

- 请求时间、模型名、渠道
- Token 标识（脱敏）
- 输入/输出 Token 数、费用
- 延迟、请求 ID
- 状态（成功/失败）

## 筛选

支持按以下维度筛选：

| 筛选条件 | 说明 |
| --- | --- |
| 时间范围 | 起止时间戳 |
| 模型 | 按模型名过滤 |
| Token | 按 Key 名称过滤 |
| 渠道 | 按上游渠道 ID 过滤 |
| 状态 | 成功/失败 |

## 统计摘要

使用日志页面顶部显示统计摘要：总消耗、总请求数、RPM/TPM 实际吞吐。

## 数据安全

- **请求正文和响应内容不落库**，日志中仅记录元数据
- 非管理员查看日志时，管理信息（`admin_info`）自动剥离
- Key 在日志中仅显示脱敏标识（如 `sk-****...****`）
