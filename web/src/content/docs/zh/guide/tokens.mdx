# Token 额度

Token 额度是你账户中可用的调用配额。每1次 API 调用的消耗根据模型定价和实际使用的 Token 数计算。

## 查看额度

- **控制台仪表盘**：显示当前余额、累计消耗、24 小时用量趋势
- **钱包页面**：余额、累计消耗、API 请求总数
- **财务明细**：账本流水（充值/消费/退款/调账）和消费明细（按项目/Key/模型/时间筛选）

## 充值

在钱包页面选择充值方式，按提示完成支付。充值记录可在「充值记录」中查看。

## 额度消耗

每次 API 调用按以下规则扣费：

1. 请求到达时**预扣费**（按模型输入价格估算）
2. 流式/非流式响应结束后**结算**（按实际 usage 精确扣费，多退少补）
3. 计费在 `使用日志` 中可查每条请求的详细费用

## 余额不足

当余额不足时，请求返回 HTTP 403，错误码 `insufficient_user_quota`。不会产生欠费——系统严格预扣费，余额不足时直接拒绝请求。

## 冻结余额

平台管理员可对账户执行冻结操作，冻结的额度不可用于消费。解冻后恢复可用。
