# 个人设置

在 **个人设置** 页面管理你的账户信息和偏好。

## 基本设置

- 修改显示名称
- 修改密码
- 绑定/解绑第三方登录（GitHub、Discord、OIDC 等）

## 安全设置

- **两步验证（2FA）**：开启后登录需要验证码，支持 TOTP 应用
- **Passkey**：支持 WebAuthn 生物识别登录
- **登录会话管理**：查看和撤销活跃的登录设备

## 通知设置

- 配置 Webhook 地址接收平台通知
- 配置邮件通知
- 支持 Bark、Gotify 等推送渠道

## 邀请

- 查看你的邀请码和邀请链接
- 查看邀请奖励记录
