# 预算与限流配置

## Key 预算

- Token 可设置 `daily_quota`（日预算）与 `monthly_quota`（月预算），按自然日/月从消费日志聚合，超限返回 429。
- 0 表示不限制。聚合结果缓存于 Redis（日键 25h / 月键 35d），缓存失效时最多延迟一个缓存周期。
- 日/月预算与总预算（remain_quota）叠加生效，任一超限即拒绝。

## 分层限流

- 作用域与配置来源：
  - 企业：Company 字段（后端，UI 后续批次）
  - 用户：既有分组级 RPM（系统设置）
  - 项目：BusinessProject 字段（预算预占之外）
  - Key：Token 字段（表单可配）
  - 模型：环境变量 `MODEL_RATE_LIMIT_RPM` / `MODEL_RATE_LIMIT_TPM`（0=不限，全模型统一）
  - 渠道：Channel 字段（表单可配）
- RPM 为精确请求数（60 秒固定窗口）；TPM 为预估（按请求输入 tokens 计数，流式结束不回溯；`max_tokens` 不计入）。
- 渠道级超限直接 429，不自动切换渠道。

## 并发限制

- 企业/项目/Key 可设置 `max_concurrent_requests`（同时处理中请求数）。
- 实现为 Redis 原子借还计数（TTL 12h 防泄漏），Redis 不可用时回退进程内计数（单节点语义）。
- 并发拒绝的请求不消耗预算、不产生消费日志。
